# Local conversation walkthrough

This is a local prototype, not a public judging URL. Start it using the README, open http://127.0.0.1:5173, and choose **Start demo session**.

1. Choose **Start conversation** on **Followed near the north gate**. Play the original recording in the conversation. Observe the clearly labeled scripted coordinator reply.
2. Answer **University campus, beside the library**, then **Injuries reported**. Inspect the incident panel: officer-reported location, source quotes and service need indicators remain distinct.
3. Ask **Why this recommendation?**, or type **Correction: the south gate, beside the library**. Earlier messages remain available.
4. Open **Review and decide**. Police, Medical and Emergency are selected from this sample assessment; add Fire to try four recipients. Review each SMS preview, save with **Send review**, then **Approve simulation**. The final report shows **SMS sent (simulation)** and retains the human's corrections. No emergency service is contacted.
5. Click **Open Medical incident view** in the simulated outbox. A new tab shows the service's message, reviewed report, original report/transcript and clarification answers. Access requires the same authenticated demo session; another session cannot open the report.
6. Reload to verify persistence, try the mobile context panel, and reset the session to remove its data.

Try **Kitchen equipment enquiry** to contrast a benign weapon mention, and **Unclear noise outside** to see uncertainty. Unexpected free-form replies in local mode receive a transparent limitation message. Real Gemini interpretation, deployment access and model-quality evidence await the selected cloud project.
